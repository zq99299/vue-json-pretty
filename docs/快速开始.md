# 快速开始

> 5 分钟快速上手 vue-json-pretty 组件

## 学习目标

通过本教程，您将学会：
- 安装并引入 vue-json-pretty 组件
- 渲染第一个 JSON 数据
- 理解基本配置选项

## 前置条件

开始之前，请确保您的开发环境满足以下要求：
- Vue 3.x 项目
- Node.js 14.0 或更高版本
- npm 或 yarn 包管理器

## 步骤

### 步骤 1：安装组件

使用 npm 或 yarn 安装 vue-json-pretty：

```bash
# 使用 npm
npm install vue-json-pretty

# 或使用 yarn
yarn add vue-json-pretty
```

### 步骤 2：引入组件

在您的 Vue 组件中引入 vue-json-pretty 和样式文件：

```vue
<template>
  <div class="container">
    <vue-json-pretty :data="jsonData" />
  </div>
</template>

<script setup>
import { ref } from 'vue';
import VueJsonPretty from 'vue-json-pretty';
import 'vue-json-pretty/dist/styles.css';

const jsonData = ref({
  name: 'vue-json-pretty',
  version: '2.0.0',
  description: 'A JSON tree view component for Vue.js',
  author: {
    name: 'Developer',
    email: 'dev@example.com'
  },
  keywords: ['vue', 'json', 'tree', 'view']
});
</script>

<style scoped>
.container {
  padding: 20px;
}
</style>
```

### 步骤 3：运行项目

启动您的开发服务器：

```bash
# 使用 npm
npm run dev

# 或使用 yarn
yarn dev
```

## 验证

打开浏览器访问您的应用，您应该能看到：
- ✅ JSON 数据以树形结构展示
- ✅ 可以展开/收缩对象和数组节点
- ✅ 语法高亮显示不同类型的数据

## 基础配置

### 设置主题

vue-json-pretty 支持亮色和暗色主题：

```vue
<template>
  <!-- 亮色主题（默认） -->
  <vue-json-pretty :data="data" theme="light" />
  
  <!-- 暗色主题 -->
  <vue-json-pretty :data="data" theme="dark" />
</template>
```

### 控制展开深度

使用 `deep` 属性控制初始展开深度：

```vue
<template>
  <!-- 只展开前 2 层 -->
  <vue-json-pretty :data="data" :deep="2" />
</template>
```

### 显示行号

使用 `show-line-number` 属性显示行号：

```vue
<template>
  <vue-json-pretty 
    :data="data" 
    :show-line-number="true" 
  />
</template>
```

### 自定义根路径

使用 `root-path` 属性自定义根节点名称：

```vue
<template>
  <vue-json-pretty 
    :data="data" 
    root-path="response" 
  />
</template>
```

## 完整示例

```vue
<template>
  <div class="json-viewer">
    <vue-json-pretty
      :data="apiResponse"
      :deep="3"
      :show-line="true"
      :show-line-number="true"
      :show-double-quotes="true"
      :show-length="true"
      theme="light"
      root-path="res"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue';
import VueJsonPretty from 'vue-json-pretty';
import 'vue-json-pretty/dist/styles.css';

const apiResponse = ref({
  status: 200,
  message: 'Success',
  data: {
    users: [
      { id: 1, name: 'Alice', age: 25 },
      { id: 2, name: 'Bob', age: 30 }
    ],
    total: 2,
    page: 1
  }
});
</script>

<style scoped>
.json-viewer {
  padding: 20px;
  background: #f5f5f5;
  border-radius: 8px;
}
</style>
```

## 常见问题

### Q: 组件没有样式？

**A**: 确保引入了样式文件：
```javascript
import 'vue-json-pretty/dist/styles.css';
```

### Q: 数据更新后视图没有更新？

**A**: 确保使用 `ref` 或 `reactive` 包装数据：
```javascript
const data = ref({ /* ... */ }); // ✅ 正确
// const data = { /* ... */ };   // ❌ 错误
```

### Q: 如何处理大数据量？

**A**: 使用虚拟滚动功能：
```vue
<vue-json-pretty 
  :data="largeData" 
  :virtual="true"
  :height="600"
/>
```
