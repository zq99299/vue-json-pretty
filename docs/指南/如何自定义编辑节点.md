# 如何自定义编辑节点？

## 问题描述

用户需要自定义节点的编辑交互方式，例如：

- 使用 `renderNodeValue` 插槽渲染链接时，链接无法正常导航
- 需要通过编辑图标而非点击值来触发编辑
- 需要使用自定义的编辑面板替代内置输入框
- 需要编程方式控制编辑状态

## 前置条件

- 已安装 @zhuqiang/vue-json-pretty
- 已了解基础的组件使用
- 了解 Vue 3 的 ref 和响应式系统
- 了解 `renderNodeValue` 插槽的基本用法

## 编辑模式概览

组件提供三种编辑触发方式和两种输入框模式，可以灵活组合：

| | 内置输入框 (`editableInput: true`) | 自定义输入框 (`editableInput: false`) |
|---|---|---|
| **click 触发** | 点击值 → 内置输入框 | 点击值 → 外部编辑 UI |
| **dblclick 触发** | 双击值 → 内置输入框 | 双击值 → 外部编辑 UI |
| **custom 触发** | API 触发 → 内置输入框 | API 触发 → 外部编辑 UI |

## 解决方案

### 方案 1：使用内置编辑（最简单）

适用于：不需要自定义渲染，直接点击/双击编辑值。

```vue
<template>
  <vue-json-pretty
    v-model:data="data"
    :editable="true"
    editable-trigger="click"
  />
</template>

<script setup>
import { ref } from 'vue';

const data = ref({
  name: 'test',
  age: 25,
  active: true
});
</script>
```

### 方案 2：自定义触发 + 内置输入框

适用于：需要通过图标等自定义方式触发编辑，但使用内置输入框编辑值。

```vue
<template>
  <vue-json-pretty
    ref="jsonTreeRef"
    v-model:data="data"
    :editable="true"
    editable-trigger="custom"
    :editable-input="true"
  >
    <template #renderNodeValue="{ node, defaultValue }">
      <span>{{ defaultValue }}</span>
      <span
        v-if="node.type === 'content'"
        class="edit-icon"
        @click.stop="handleEdit(node)"
      >✎</span>
    </template>
  </vue-json-pretty>
</template>

<script setup>
import { ref } from 'vue';

const jsonTreeRef = ref();
const data = ref({ name: 'test', age: 25 });

const handleEdit = (node) => {
  jsonTreeRef.value?.startEdit(node.path);
};
</script>

<style scoped>
.edit-icon {
  display: inline-block;
  margin-left: 4px;
  cursor: pointer;
  opacity: 0;
  font-size: 12px;
  color: #999;
  transition: opacity 0.2s;
}

.edit-icon:hover {
  color: #1890ff;
}

/* 悬停时显示编辑图标 */
:deep(.vjs-value:hover) .edit-icon {
  opacity: 1;
}
</style>
```

### 方案 3：完全自定义编辑

适用于：需要完全自定义编辑 UI，例如链接值需要正常导航、编辑面板需要特殊样式等。

```vue
<template>
  <div>
    <vue-json-pretty
      ref="jsonTreeRef"
      v-model:data="data"
      :editable="true"
      editable-trigger="custom"
      :editable-input="false"
    >
      <template #renderNodeValue="{ node, defaultValue }">
        <span class="custom-value" :class="{ 'is-editing': editingPath === node.path }">
          <a
            v-if="isUrl(node.content)"
            :href="node.content"
            target="_blank"
            rel="noopener noreferrer"
            class="custom-link"
          >{{ node.content }}</a>
          <template v-else>{{ defaultValue }}</template>
          <span
            v-if="node.type === 'content'"
            class="edit-icon"
            @click.stop="handleEditClick(node)"
          >✎</span>
        </span>
      </template>
    </vue-json-pretty>

    <!-- 自定义编辑面板 -->
    <div v-if="editingPath" class="custom-edit-panel">
      <h4>Editing: {{ editingPath }}</h4>
      <input
        v-model="editValue"
        class="custom-edit-input"
        @keyup.enter="handleSave"
        @keyup.escape="handleCancel"
      />
      <button class="btn btn-primary" @click="handleSave">Save</button>
      <button class="btn" @click="handleCancel">Cancel</button>
    </div>
  </div>
</template>

<script setup>
import { ref, nextTick } from 'vue';

const jsonTreeRef = ref();
const editInputRef = ref();
const editingPath = ref('');
const editValue = ref('');

const data = ref({
  status: 200,
  message: 'OK',
  url: 'https://example.com/api',
  config: { timeout: 5000 }
});

const isUrl = (content) =>
  typeof content === 'string' &&
  (content.startsWith('http://') || content.startsWith('https://'));

const handleEditClick = (node) => {
  editingPath.value = node.path;
  editValue.value =
    node.content === null ? 'null'
    : node.content === undefined ? 'undefined'
    : String(node.content);
  jsonTreeRef.value?.startEdit(node.path);
  nextTick(() => {
    editInputRef.value?.focus();
  });
};

const handleSave = () => {
  if (!editingPath.value) return;
  let value = editValue.value;
  if (value === 'null') value = null;
  else if (value === 'undefined') value = undefined;
  else if (value === 'true') value = true;
  else if (value === 'false') value = false;
  else if (!isNaN(Number(value)) && value.trim() !== '') value = Number(value);
  else if (
    (value.startsWith('"') && value.endsWith('"')) ||
    (value.startsWith("'") && value.endsWith("'"))
  ) {
    value = value.slice(1, -1);
  }
  jsonTreeRef.value?.updateValue(editingPath.value, value);
  handleCancel();
};

const handleCancel = () => {
  jsonTreeRef.value?.stopEdit();
  editingPath.value = '';
  editValue.value = '';
};
</script>
```

## API 说明

### startEdit(path)

进入编辑模式，激活指定节点的编辑状态。

```javascript
jsonTreeRef.value?.startEdit('root.data[0].name');
```

### stopEdit()

退出编辑模式。

```javascript
jsonTreeRef.value?.stopEdit();
```

### updateValue(path, value)

更新指定节点的值，触发 `update:data` 事件。

```javascript
jsonTreeRef.value?.updateValue('root.data[0].name', 'new value');
jsonTreeRef.value?.updateValue('root.data[0].count', 42);
jsonTreeRef.value?.updateValue('root.data[0].active', true);
jsonTreeRef.value?.updateValue('root.data[0].extra', null);
```

## 故障排除

### 问题：使用插槽渲染链接时，点击链接进入编辑模式而非导航

**原因**：内置触发器（click/dblclick）会拦截所有点击事件

**解决方案**：使用 `editableTrigger="custom"` 禁用内置触发器，通过 API 控制编辑

### 问题：自定义模式下点击值没有反应

**原因**：`editableTrigger="custom"` 不绑定任何点击事件

**解决方案**：在 `renderNodeValue` 插槽中添加编辑图标，通过 `startEdit(path)` 触发编辑

### 问题：`editableInput: false` 时编辑模式没有输入框

**原因**：`editableInput: false` 禁用了内置输入框

**解决方案**：在外部创建自定义编辑面板，通过 `updateValue(path, value)` 保存修改

### 问题：`updateValue` 后数据没有更新

**原因**：未使用 `v-model:data` 或未监听 `update:data` 事件

**解决方案**：

```vue
<!-- 方式 1：使用 v-model:data（推荐） -->
<vue-json-pretty v-model:data="data" ... />

<!-- 方式 2：监听事件 -->
<vue-json-pretty :data="data" @update:data="handleUpdate" ... />
```
