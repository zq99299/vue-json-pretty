# 如何展开收缩节点？

## 问题描述

用户需要通过编程方式控制节点的展开和收缩，例如：
- 展开所有子节点
- 只展开指定层级的子节点
- 收缩特定节点
- 实现自定义的展开/收缩按钮

## 前置条件

- 已安装 @zhuqiang/vue-json-pretty
- 已了解基础的组件使用
- 了解 Vue 3 的 ref 和响应式系统

## 解决方案

### 方案 1：通过 ref 调用方法

使用 `ref` 获取组件实例，然后调用暴露的方法：

```vue
<template>
  <div>
    <vue-json-pretty ref="jsonTreeRef" :data="data" />
    
    <div class="controls">
      <button @click="expandAll">展开所有</button>
      <button @click="collapseAll">收缩所有</button>
      <button @click="expandFirstLevel">展开第 1 级</button>
      <button @click="collapseFirstLevel">收缩第 1 级</button>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import VueJsonPretty from '@zhuqiang/vue-json-pretty';
import '@zhuqiang/vue-json-pretty/dist/styles.css';

const jsonTreeRef = ref();
const data = ref({
  users: [
    { id: 1, name: 'Alice', profile: { age: 25, city: 'NYC' } },
    { id: 2, name: 'Bob', profile: { age: 30, city: 'LA' } }
  ]
});

// 展开所有节点
const expandAll = () => {
  jsonTreeRef.value?.expandAll();
};

// 收缩所有节点
const collapseAll = () => {
  jsonTreeRef.value?.collapseAll();
};

// 展开第 1 级子节点
const expandFirstLevel = () => {
  jsonTreeRef.value?.expandAll('root', 1);
};

// 收缩第 1 级子节点
const collapseFirstLevel = () => {
  jsonTreeRef.value?.collapseAll('root', 1);
};
</script>

<style scoped>
.controls {
  margin-top: 20px;
  display: flex;
  gap: 10px;
}

button {
  padding: 8px 16px;
  border: 1px solid #ddd;
  border-radius: 4px;
  background: white;
  cursor: pointer;
}

button:hover {
  background: #f0f0f0;
}
</style>
```

### 方案 2：通过插槽参数调用

在 `renderNodeActions` 插槽中使用提供的展开/收缩方法：

```vue
<template>
  <vue-json-pretty :data="data" :selected-value="selectedNode">
    <template #renderNodeActions="{ node, expandAll, collapseAll, expandFirstLevel, collapseFirstLevel }">
      <div v-if="selectedNode === node.path" class="node-actions">
        <button @click.stop="expandFirstLevel()">📂 展开第 1 级</button>
        <button @click.stop="expandAll()">📂 展开所有</button>
        <button @click.stop="collapseFirstLevel()">📁 收缩第 1 级</button>
        <button @click.stop="collapseAll()">📁 收缩所有</button>
      </div>
    </template>
  </vue-json-pretty>
</template>

<script setup>
import { ref } from 'vue';
import VueJsonPretty from '@zhuqiang/vue-json-pretty';
import '@zhuqiang/vue-json-pretty/dist/styles.css';

const selectedNode = ref('');
const data = ref({ /* ... */ });
</script>
```

## 层级控制

### 理解层级深度

@zhuqiang/vue-json-pretty 支持精确控制展开/收缩的层级深度：

```
root (level 0)
├─ root.users (level 1)        ← 第 1 级
│  ├─ root.users[0] (level 2)  ← 第 2 级
│  │  └─ root.users[0].profile (level 3) ← 第 3 级
│  └─ root.users[1] (level 2)
└─ root.config (level 1)
```

### 两种操作模式

#### 精确模式（默认）

只操作第 N 级子节点，不影响其他层级：

```javascript
// 只展开第 1 级子节点
jsonTreeRef.value?.expandAll('root', 1);
// 结果：展开 root.users 和 root.config，但不展开更深层级

// 只展开第 2 级子节点
jsonTreeRef.value?.expandAll('root', 2, false);
// 结果：展开 root.users[0] 和 root.users[1]，不影响第 1 级
```

#### 级联模式

操作前 N 级子节点，确保父级都已展开：

```javascript
// 展开前 2 级子节点（级联模式）
jsonTreeRef.value?.expandAll('root', 2, true);
// 结果：展开第 1 级和第 2 级，确保第 2 级可见

// 展开前 3 级子节点（级联模式）
jsonTreeRef.value?.expandAll('root', 3, true);
// 结果：展开第 1、2、3 级

// 使用便捷方法
jsonTreeRef.value?.expandToLevel('root', 3);
```

### cascade 参数说明

| 参数值 | 说明 | 适用场景 |
|--------|------|----------|
| `false`（默认） | 只操作第 N 级 | 精确控制某一层级 |
| `true` | 操作前 N 级 | 用户想看到第 N 级内容时 |

### 展开指定层级

```javascript
// 精确模式：只展开第 1 级子节点
jsonTreeRef.value?.expandAll('root', 1);

// 精确模式：只展开第 2 级子节点
jsonTreeRef.value?.expandAll('root', 2, false);

// 级联模式：展开前 2 级子节点
jsonTreeRef.value?.expandAll('root', 2, true);

// 级联模式：使用便捷方法
jsonTreeRef.value?.expandToLevel('root', 2);

// 展开所有子节点
jsonTreeRef.value?.expandAll('root');
// 或
jsonTreeRef.value?.expandAll('root', Infinity);
```

### 重要说明

**精确模式** (`cascade: false`)：
- `depth = 1`：只操作第 1 级子节点
- `depth = 2`：只操作第 2 级子节点（**不影响第 1 级**）

**级联模式** (`cascade: true`)：
- `depth = 1`：操作第 1 级
- `depth = 2`：操作第 1 级和第 2 级
- `depth = N`：操作第 1 到第 N 级

## 高级用法

### 展开特定节点

```javascript
// 展开特定节点下的所有子节点
jsonTreeRef.value?.expandAll('root.users[0]');

// 只展开特定节点下的第 1 级子节点
jsonTreeRef.value?.expandAll('root.users[0]', 1);
```

### 获取子节点路径

```javascript
// 获取所有子节点路径
const paths = jsonTreeRef.value?.getChildrenPaths('root.users');

// 获取第 1 级子节点路径
const firstLevelPaths = jsonTreeRef.value?.getChildrenPaths('root.users', 1);

console.log(paths);
// ['root.users[0]', 'root.users[1]']
```

### 条件性展开

```javascript
// 根据条件展开节点
const expandNodesWithCondition = () => {
  const allPaths = jsonTreeRef.value?.getChildrenPaths('root');
  
  allPaths?.forEach(path => {
    // 只展开包含特定数据的节点
    if (path.includes('important')) {
      jsonTreeRef.value?.expandAll(path);
    }
  });
};
```

## 完整示例：带操作按钮的 JSON 查看器

```vue
<template>
  <div class="json-viewer">
    <vue-json-pretty
      ref="jsonTreeRef"
      :data="data"
      :selected-value="selectedNode"
      :selectable-type="'single'"
      @node-click="handleNodeClick"
    >
      <template #renderNodeActions="{ node, expandAll, collapseAll }">
        <div v-if="selectedNode === node.path && hasCollapsibleChildren(node)" class="node-actions">
          <button class="btn" @click.stop="expandAll()">📂 展开所有</button>
          <button class="btn" @click.stop="collapseAll()">📁 收缩所有</button>
        </div>
      </template>
    </vue-json-pretty>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import VueJsonPretty from '@zhuqiang/vue-json-pretty';
import '@zhuqiang/vue-json-pretty/dist/styles.css';

const jsonTreeRef = ref();
const selectedNode = ref('');

const data = ref({
  users: [
    { id: 1, name: 'Alice', profile: { age: 25, city: 'NYC' } },
    { id: 2, name: 'Bob', profile: { age: 30, city: 'LA' } }
  ],
  config: {
    theme: 'dark',
    settings: { autoSave: true, notifications: false }
  }
});

const handleNodeClick = (node) => {
  selectedNode.value = node.path;
};

// 检查节点是否有可折叠的子节点
const hasCollapsibleChildren = (node) => {
  if (node.type !== 'objectStart' && node.type !== 'arrayStart') {
    return false;
  }
  
  const childrenPaths = jsonTreeRef.value?.getChildrenPaths(node.path, 1) || [];
  return childrenPaths.length > 0;
};
</script>

<style scoped>
.json-viewer {
  padding: 20px;
}

.node-actions {
  display: inline-flex;
  gap: 8px;
  margin-left: 12px;
}

.btn {
  padding: 4px 8px;
  font-size: 12px;
  border: 1px solid #ddd;
  border-radius: 4px;
  background: white;
  cursor: pointer;
}

.btn:hover {
  background: #f0f0f0;
}
</style>
```

## 故障排除

### 问题：展开/收缩按钮不显示

**原因**：节点没有可折叠的子节点

**解决方案**：
1. 检查节点是否包含对象或数组类型的子节点
2. 使用 `hasCollapsibleChildren` 方法判断节点是否可折叠
3. 只在节点类型为 `objectStart` 或 `arrayStart` 时显示按钮

### 问题：展开所有没有效果

**原因**：可能传递了错误的事件对象

**解决方案**：
确保调用方法时使用括号：
```vue
<!-- ✅ 正确 -->
<button @click.stop="expandAll()">展开所有</button>

<!-- ❌ 错误 -->
<button @click.stop="expandAll">展开所有</button>
```

### 问题：层级控制不符合预期

**原因**：误解了 `depth` 参数的含义

**解决方案**：
- `depth = 1` 表示只操作第 1 级，不是"展开前 1 层"
- 如果想展开前 N 层，需要多次调用或使用其他逻辑

### 问题：操作按钮在开始和结束节点都显示

**原因**：对象/数组有开始和结束两个节点

**解决方案**：
只在开始节点显示操作按钮：
```vue
<template #renderNodeActions="{ node }">
  <div v-if="node.type === 'objectStart' || node.type === 'arrayStart'">
    <!-- 操作按钮 -->
  </div>
</template>
```
