# 更新日志
本更新日志只记录 fork 之后的更新日志

- 增加插件文档
- 为树形组件的展开/折叠功能添加级联模式参数(cascade)
- 为树形组件增加搜索功能
- 修复编辑节点数据 BUG：当使用插槽时，无法进入编辑输入框；同时提供自定义触发编辑方式，提供编程方式编辑，让外部可以有更灵活的编辑体验
  - 新增 `editableTrigger="custom"` 选项：禁用内置点击/双击触发，通过 API 编程控制编辑
  - 新增 `editableInput` 属性：控制编辑模式下是否显示内置输入框，支持完全自定义编辑 UI
  - 新增 `startEdit(path)`、`stopEdit()`、`updateValue(path, value)` API 方法
  - 新增 [如何自定义编辑节点](指南/如何自定义编辑节点.md) 使用指南
