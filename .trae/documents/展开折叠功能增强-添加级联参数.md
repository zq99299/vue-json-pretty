# 展开折叠功能增强：添加级联参数

## 问题分析

### 当前行为
- `expandAll(path, 1)` - 只展开第 1 级子节点
- `expandAll(path, 2)` - 只展开第 2 级子节点
- `expandAll(path, 3)` - 只展开第 3 级子节点

### 问题场景
1. **展开问题**：用户想展开第 2 级，但第 1 级是折叠的，展开第 2 级后看不到效果
2. **折叠问题**：用户看到第 2 级后点击折叠，效果可见（因为第 1 级已展开）

### 解决方案
添加 `cascade` 参数，让使用者决定操作模式：
- `cascade: true` - 级联模式：展开/折叠前 N 级（展开第 2 级时自动展开第 1 级）
- `cascade: false` - 精确模式：只操作第 N 级（当前行为，默认值）

## 使用示例

### 级联展开（推荐场景）
```javascript
// 展开前 3 级（自动展开第 1、2、3 级）
jsonTreeRef.value?.expandAll('root', 3, true);

// 折叠前 3 级
jsonTreeRef.value?.collapseAll('root', 3, true);
```

### 精确展开（当前行为）
```javascript
// 只展开第 3 级（不影响第 1、2 级）
jsonTreeRef.value?.expandAll('root', 3, false);

// 只折叠第 3 级
jsonTreeRef.value?.collapseAll('root', 3, false);
```

### 插槽中使用
```vue
<template #renderNodeActions="{ node, expandToLevel, collapseToLevel }">
  <button @click.stop="expandToLevel(3)">📂 展开前 3 级</button>
  <button @click.stop="collapseToLevel(3)">📁 折叠前 3 级</button>
</template>
```

## 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| path | string | - | 节点路径 |
| depth | number | Infinity | 层级深度 |
| cascade | boolean | false | 是否级联操作 |

### cascade 参数详解

- `cascade: false`（默认）：只操作第 N 级
  - `expandAll('root', 2, false)` - 只展开第 2 级
  - 适用于：精确控制某一层级的展开/折叠

- `cascade: true`：操作前 N 级
  - `expandAll('root', 2, true)` - 展开第 1 级和第 2 级
  - 适用于：用户想看到第 N 级内容时，确保父级都已展开
