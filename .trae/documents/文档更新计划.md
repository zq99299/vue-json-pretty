### 3.2 指南/如何展开收缩节点.md（How-to Guide）

**目标**：解决用户如何实现节点展开收缩的问题

**结构**：
```markdown
# 如何展开收缩节点？

## 问题描述

用户需要通过编程方式控制节点的展开和收缩，例如：
- 展开所有子节点
- 只展开指定层级的子节点
- 收缩特定节点

## 前置条件
- 已安装 vue-json-pretty
- 已了解基础的组件使用

## 解决方案

### 方案 1：通过 ref 调用方法

\`\`\`vue
<template>
  <vue-json-pretty ref="jsonTreeRef" :data="data" />
  <button @click="expandAll">展开所有</button>
</template>

<script setup>
import { ref } from 'vue';

const jsonTreeRef = ref();
const data = ref({ /* ... */ });

const expandAll = () => {
  jsonTreeRef.value?.expandAll();
};
</script>
\`\`\`

### 方案 2：通过插槽参数调用

\`\`\`vue
<template>
  <vue-json-pretty :data="data">
    <template #renderNodeActions="{ node, expandAll, collapseAll }">
      <button @click="expandAll()">展开所有</button>
      <button @click="collapseAll()">收缩所有</button>
    </template>
  </vue-json-pretty>
</template>
\`\`\`

## 层级控制

### 只操作指定层级

\`\`\`javascript
// 只展开第 1 级子节点
jsonTreeRef.value?.expandAll(nodePath, 1);

// 只展开第 2 级子节点
jsonTreeRef.value?.expandAll(nodePath, 2);

// 展开所有子节点
jsonTreeRef.value?.expandAll(nodePath);
\`\`\`

**重要说明**：
- `depth = 1`：只操作第 1 级子节点
- `depth = 2`：只操作第 2 级子节点（不影响第 1 级）
- 不传 depth：操作所有子节点

## 故障排除

### 问题：展开/收缩按钮不显示

**原因**：节点没有可折叠的子节点

**解决方案**：检查节点是否包含对象或数组类型的子节点

### 问题：展开所有没有效果

**原因**：可能传递了错误的事件对象

**解决方案**：确保调用方法时使用括号 `expandAll()` 而不是 `expandAll`
```

### 3.3 参考/Methods方法.md（Reference）

**目标**：提供完整的方法 API 参考

**结构**：
```markdown
# Methods 方法参考

## 概述

通过 `ref` 可以调用以下方法来控制组件行为。

## 方法列表

### expandAll

展开指定节点下的子节点。

**签名**：
\`\`\`typescript
expandAll(path?: string, depth?: number): void
\`\`\`

**参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 否 | - | 节点路径，不传则展开所有节点 |
| depth | number | 否 | Infinity | 层级深度 |

**depth 参数说明**：
- `1`：只展开第 1 级子节点
- `2`：只展开第 2 级子节点
- `Infinity`：展开所有子节点（默认）

**示例**：

\`\`\`vue
<template>
  <vue-json-pretty ref="jsonTreeRef" :data="data" />
</template>

<script setup>
import { ref } from 'vue';

const jsonTreeRef = ref();

// 展开所有节点
jsonTreeRef.value?.expandAll();

// 展开指定节点下的所有子节点
jsonTreeRef.value?.expandAll('root.data');

// 只展开第 1 级子节点
jsonTreeRef.value?.expandAll('root.data', 1);
</script>
\`\`\`

---

### collapseAll

收缩指定节点下的子节点。

**签名**：
\`\`\`typescript
collapseAll(path?: string, depth?: number): void
\`\`\`

**参数**：同 `expandAll`

**示例**：

\`\`\`javascript
// 收缩所有节点
jsonTreeRef.value?.collapseAll();

// 只收缩第 2 级子节点
jsonTreeRef.value?.collapseAll('root.data', 2);
\`\`\`

---

### getChildrenPaths

获取指定节点下的子节点路径。

**签名**：
\`\`\`typescript
getChildrenPaths(path: string, depth?: number): string[]
\`\`\`

**参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| path | string | 是 | - | 节点路径 |
| depth | number | 否 | Infinity | 层级深度 |

**返回值**：子节点路径数组

**示例**：

\`\`\`javascript
// 获取所有子节点路径
const paths = jsonTreeRef.value?.getChildrenPaths('root.data');

// 获取第 1 级子节点路径
const firstLevelPaths = jsonTreeRef.value?.getChildrenPaths('root.data', 1);

console.log(paths); // ['root.data[0]', 'root.data[1]', 'root.data[2]']
\`\`\`

## 注意事项

1. **节点路径格式**：路径使用点号和方括号表示，如 `root.data[0].name`
2. **层级深度**：只操作指定层级的节点，不影响其他层级
3. **性能考虑**：大数据量时建议使用虚拟滚动
```

### 3.4 参考/DataStructures数据结构.md（Reference）

**目标**：详细说明所有数据结构

**结构**：
```markdown
# Data Structures 数据结构参考

## NodeData

节点数据类型，用于事件回调和插槽参数。

### 类型定义

\`\`\`typescript
interface NodeData {
  id: number;
  key?: string;
  index?: number;
  path: string;
  level: number;
  type: NodeType;
  content: string | number | null | boolean;
  length: number;
  showComma: boolean;
}
\`\`\`

### 属性说明

| 属性名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | number | 节点唯一标识 | `5` |
| key | string \| undefined | 节点键名（对象属性） | `'name'` |
| index | number \| undefined | 数组索引 | `0` |
| path | string | 节点路径 | `'root.data[0].name'` |
| level | number | 节点层级（从 0 开始） | `2` |
| type | NodeType | 节点类型 | `'content'` |
| content | string \| number \| null \| boolean | 节点内容 | `'John'` |
| length | number | 子元素数量 | `3` |
| showComma | boolean | 是否显示逗号 | `true` |

### 节点类型（NodeType）

\`\`\`typescript
type NodeType =
  | 'content'          // 普通内容节点
  | 'objectStart'      // 对象开始节点 `{`
  | 'objectEnd'        // 对象结束节点 `}`
  | 'objectCollapsed'  // 对象折叠节点 `{...}`
  | 'arrayStart'       // 数组开始节点 `[`
  | 'arrayEnd'         // 数组结束节点 `]`
  | 'arrayCollapsed';  // 数组折叠节点 `[...]`
\`\`\`

### 使用示例

\`\`\`javascript
{
  id: 5,
  key: 'name',
  path: 'root.user.name',
  level: 2,
  type: 'content',
  content: 'John',
  length: 1,
  showComma: true
}
\`\`\`

---

## NodeActions

节点操作类型，用于 `renderNodeActions` 插槽参数。

### 类型定义

\`\`\`typescript
interface NodeActions {
  copy: () => void;
  expandAll: (depth?: number) => void;
  collapseAll: (depth?: number) => void;
  expandFirstLevel: () => void;
  collapseFirstLevel: () => void;
}
\`\`\`

### 方法说明

| 方法名 | 参数 | 说明 |
|--------|------|------|
| copy | 无 | 复制节点数据到剪贴板 |
| expandAll | depth?: number | 展开子节点 |
| collapseAll | depth?: number | 收缩子节点 |
| expandFirstLevel | 无 | 展开第 1 级子节点 |
| collapseFirstLevel | 无 | 收缩第 1 级子节点 |

### 使用示例

\`\`\`vue
<template>
  <vue-json-pretty :data="data">
    <template #renderNodeActions="{ node, expandAll, collapseAll }">
      <button @click="expandAll()">展开所有</button>
      <button @click="collapseAll()">收缩所有</button>
      <button @click="expandAll(1)">展开第 1 级</button>
    </template>
  </vue-json-pretty>
</template>
\`\`\`
```
